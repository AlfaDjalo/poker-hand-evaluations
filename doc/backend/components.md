# Backend components

This document lists the main backend modules and a short description of
their responsibilities. It is intended to help new contributors quickly
understand the architecture.

- `backend/server.py`
  - Primary FastAPI application. Exposes `/evaluate` and `/showdown`.
  - Normalizes input, calls native bindings, and returns JSON to clients.

- `bindings/` (C++ / pybind11 wrappers)
  - Implements `equity_wrapper` (and other thin wrappers) that translate
    between Python structures and native OMPEval/C++ APIs.
  - The compiled modules live in the `bindings/` package (built with
    `python setup.py build_ext --inplace` or CMake depending on platform).

- `OMPEval/` or `bindings` native sources
  - The core, high-performance evaluator that computes hand equity and
    rankings. This is the heavy, optimized C++ code used by the wrapper.

- `python_hand_evaluator.py`
  - Pure-Python evaluator(s) used for tests or fallbacks. Slower but
    easy to debug. Not used in production for heavy workloads.

- `db_plo.py`, `db.py`
  - Database access helpers. `db_plo` holds domain-specific queries for
    PLO datasets used by the ML pipeline.

- `chart/` (frontend data dump)
  - Contains JSON chart data generated by backend jobs when requested.
